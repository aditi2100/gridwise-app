# GridWise

GridWise turns household energy meter exports into a clear, actionable energy story. It combines client-side CSV ingestion, usage visualization, appliance estimates, and ranked interventions that balance savings, effort, and confidence.

## Product highlights

- Sample household dataset ready to explore
- In-browser CSV import with `date,kwh` support
- SVG daily usage chart with forecast window
- Estimated end-use breakdown and cost/carbon metrics
- Recommendations tied to observable usage patterns
- No data upload: imported readings stay in the browser

## Run locally

Open `index.html` in a browser. Use **Load sample data** or upload a CSV containing a numeric `kwh` column.
